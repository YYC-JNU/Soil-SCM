## 二、L4 硝化两步动力学（模型库存层）

### 2.1 phreeqc.dat N→N₂ 约束的发现（关键）

官方 `phreeqc.dat` 的 N 氧化还原平衡将任何注入溶液的无机氮热力学平衡为惰性 N₂：

- `2NO₃⁻ + 12H⁺ + 10e⁻ = N₂ + 6H₂O`，log_k = 207.08
- N₂(aq) 为 N(0) 的 master species（`N₂ = N₂`, log_k = -3.1864）

**实测证据**（pe=0~12、无 pe、加 NH₄⁺ 或加 NO₃⁻）：平衡后溶液 `N(-3)(mol/kgw)` 与 `N(5)(mol/kgw)` 均 ≈0，氮 100% 转为 N₂(g)。

**关键认知**：旧实现（v0.2.6 一步"加 NO₃⁻+2H⁺"）的施肥氮同样 100% 流失为 N₂（实测 N(5)=0）——这是**既有局限**，非 L4 引入。L4 的库存层设计首次让氮形态可追踪。

### 2.2 库存层架构决策（grilling Q1=A/Q3=A/Q4=A/Q5=A）

- **氮形态（尿素/NH₄⁺/NO₃⁻）为纯模型状态**（`SoilState.n_urea/n_nh4/n_no3`，单位 mol N），**不注入 PHREEQC 溶液平衡**（注入即被 N₂ 平衡吞没）
- **硝化产酸 `2H⁺/mol N` 注入 REACTION**——酸化效应真实进入溶液（与旧"一步产酸"的 H⁺ 量守恒）
- `advance_nitrification` 为**独立模块级函数**（升级空间：将来替换为 PHREEQC KINETICS 实现时调用方不变）
- `n_no3` 为**累计硝化量**（诊断语义，Q4=A）；库存仅统计施肥氮（降水 N 走既有溶液路径，Q5=A）

### 2.3 月度推进逻辑

```
施肥月:  n_urea += 施肥N (kg N → mol N, N_MOL_PER_KG_N)
每月:    hydrolyzed = n_urea × k1        # 尿素水解 → NH4+
         nitrified  = n_nh4 × k2         # 硝化 → NO3- (库存累计)
         REACTION 注入 H+ = 2 × nitrified # 产酸进溶液
```

### 2.4 氮形态时程验证（工单 07）

- 单月施肥酸化：pH 5.000 → 4.354 ✓
- `n_nh4` 施肥月峰值 ~649 mol（≈0.6×857：水解后当月 40% 硝化余量），非峰值月按 k₂=0.4 递减 ✓
- `n_no3` 单调累计（第 1 年 2336 mol → 第 30 年 76870 mol）✓

## 三、L5 溶液电荷平衡修正

### 3.1 原方案与实测否决（诚实记录）

L5 初版尝试"电荷盈余由 HCO₃⁻ 承担 + 总阳离子浓度物理化至 5e-5 mol/L"（红壤淋溶液量级），经实测**否决**：

1. **HCO₃⁻ 补足物理不可行**：pH=5 时 HCO₃⁻ 仅占无机碳 4%，承载 3.6e-3 mol/L 的电荷盈余需注入 0.09 mol/L 无机碳（对应 pCO₂≈2.6 atm，物理不可能），且实测 PHREEQC 数值失稳（交换位点被抽干，CaX2=0）。
2. **阳离子 5e-5 触发碱化回归**：土壤溶液体积为田间持水（8.2e5 L/ha），浓度应与交换相自洽（2e-3 量级）；5e-5 与交换相 NaX（43200 mol）严重失衡，平衡时 NaX 释放 Na⁺ 使 pH 系统性碱化漂移（fertilizer 5 年 pH 从酸化 2.9 反转为碱化 10.4）。

### 3.2 修正方案（落地）

- **`total_cation_conc` 保留 2e-3 mol/L**（土壤溶液量级，与交换相自洽，维持 v0.2.6 基线行为）
- **HCO₃⁻ 由 pCO₂ 决定**（亨利定律 + 碳酸一级解离，与 GAS_PHASE 开放体系自洽）——本版本新增的物理自洽
- **电荷盈余由 Cl⁻ 兜底**（Q13 物理必要：pH<6 时强酸阴离子是主要平衡离子）
- **`_check_charge_balance` 精确化**：从 C(4) 按解离平衡拆分 HCO₃⁻/CO₃²⁻ 计算真实电荷（替代旧 C(4) 一价简化）

### 3.3 验证

- 初始溶液 C(4) 保持 pCO₂ 平衡量级（~5.3e-4，无 0.09 暴涨）✓
- `_check_charge_balance` 电荷不平衡度 < 1e-3 ✓
- natural 30 年 pH 与 v0.2.6 一致（平缓至 6.46），多层 pH 梯度方向维持 v0.2.6 基线（表层高/底层低）✓

## 四、L4 产酸时程与单层缓冲局限（科学诚实记录）

### 4.1 现象

`fertilizer` 单层模拟在 **k₂=0.4** 下：AlX₃ 于 **第 2 年 12 月耗尽** → 第 3 年 pH 突升 **10.4**（超碱性）。

### 4.2 对照实验（k₂ 敏感性）

| k₂ | 产酸（mol H⁺/次） | fertilizer 5 年 pH 轨迹 | AlX₃ 行为 |
|----|-------------------|------------------------|-----------|
| 0.4 | 686（当月 40%） | 3.8 → 5.4 → **10.2** → 10.4 → 10.4 | y2 耗尽 |
| 1.0 | 1714（当月 100%） | 3.56 → 3.77 → 4.09 → 4.43 → 4.76 | 5 年内稳定 |
| v0.2.6（一步） | 1714 | 2.94 → 2.90 → ... → 2.88 | 30 年稳定 |

### 4.3 根因链条

```
k₂=0.4 弱产酸 → pH~4（Al 淋洗活跃区）
  → AlX₃ 被排水逐年淋失耗尽（单层排水模型，Q12*）
  → 矿物量压缩（Q1+ MINERAL_SCALE=0.001）无法回补交换 Al
  → 土壤失去主要产酸缓冲 → pH 突升
```

**性质**：既有结构局限（Q12* 单层排水 + Q1+ 矿物折中的组合）在更真实的产酸时程（L4）下的暴露，**非 L4 实现错误**。v0.2.6 的强酸化（pH 2.9 触底）只是掩盖了该机制。

### 4.4 决策与深层修复方向

- **grilling Q1=A**：k₂=0.4 保持（物理真实的红壤慢硝化）；突升接受为已知局限并如实记录，**不用参数掩盖模型缺陷**
- **grilling Q4=A**：新增 backlog 工单 **L9「矿物缓冲重新校准」**——扩大 `MINERAL_SCALE` 或改用物理矿物量 + 重新验证 P1-P5 收敛，从根源解决 fertilizer 长期 pH 突升
- **建议**：当前 fertilizer 情景科学应用应配合多层模型（n_layers≥4，推迟耗尽）与矿物量校准
