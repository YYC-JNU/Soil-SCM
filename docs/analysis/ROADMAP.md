## 1. 项目概况

Soil-SCM 是基于 PHREEQC 引擎的土壤物理化学单点模式，模拟长期施肥、酸化、淋溶与改良下的土壤化学演变（pH、盐基饱和度、交换性阳离子等）。

**当前技术栈**：
- PHREEQC 引擎：官方 `phreeqc` 包（IPhreeqc 3.8.6），简化模式兜底（phreeqpython 已废弃）
- 状态传递：SELECTED_OUTPUT + 排水模型
- 初始条件：`InitialConditionBuilder`（溶液/交换/矿物/气相）

## 3. 进行中与已知局限

### Q1+ 矿物量与自然情景碱性漂移（关键）

**现象**：仅降水情景（natural）pH 上升至 9-10（脱酸），与真实红壤淋溶（盐基流失、pH 下降）不符。

**根因（已系统诊断）**：
1. **单层模型 + 完全混合 + 排水**：交换性 Al 被溶液 Ca/K 置换解吸，超过 gibbsite 溶解度后矿物化，随排水净流失
2. AlX3 数月内耗尽（8.16×10⁴ → 0）→ 土壤脱酸 → pH 突升
3. 矿物量增大会加速矿物碱性平衡主导（kaolinite >2e6 mol 时 pH 突变 9.9）

**已尝试无效的调整**：
- AlX3 交换系数 log_k 提高（0.41→5.0）
- 入渗系数降低（0.05→0.01）
- 矿物量缩放（0.1 / 0.001）

**结论**：非参数可调，需**多分层模型**（Al 垂直迁移、盐基优先淋洗）等架构改进。

### 30 年模拟现象与机制（2026-08-11 诊断）

| 现象 | 机制 | 关联 |
|---|---|---|
| **pH 第 8 年突变**（5.5→10.2） | **交换性 Al（AlX3）缓冲库耗尽**（第 8 年 AlX3=0），非矿物 Al 耗尽；土壤失去主要产酸源 | 单层排水模型 |
| **mineral_scale 影响** | 只影响突变时间：0.001 推迟至第 8 年；0.1 第 4 月即突变（矿物多→交换 Al 矿物化加速） | 交换 Al 量本身不受 scale 影响 |
| **Cl⁻ 持续下降**（10⁻³→10⁻¹⁷） | Cl 为保守离子，被排水逐年淋洗；降水纯水无 Cl 输入 → 只出不进 | 排水模型 + 降水化学缺失（Q7） |
| **pH 升高后总 Al 反而上升** | Al(OH)₃ **两性溶解**：高 pH 时 Al(OH)₄⁻ 主导（1.3e-5），Al³⁺ 剧降（2.3e-23） | Al 化学两性 |

### 近期规划（v0.5.2 ~ v0.6.0 水文物理化重构）

> **背景**：v0.5.0/v0.5.1 水文盒子模型已如实记录基线漂移（表层 pH ~6.9）。经 `/grill-me`（2026-08-18，9 轮决策拷问，专家意见 3 份）敲定的物理化重构将彻底移除 `surface_coeff` 等非物理补丁，按**改动量/风险从小到大**分三阶段推进：

#### v0.5.2 — Green-Ampt 表层入渗（轻量替换，不动状态结构）✅ 已完成 (2026-08-18)
- [x] **废弃 `surface_coeff`**：`horton_event_infiltration` 替换为 Green-Ampt 隐式方程
      $F - \psi_f \Delta\theta \ln\left(1 + \frac{F}{\psi_f \Delta\theta}\right) = K_s t$（牛顿迭代求解）；
      降雨强度 > 入渗率时超渗产流**自然产生**，消除人为 25% 径流
- [x] **Ksat 字段拆分**（`SoilProfile` + `layer_overrides`）：
      `Ksat_surface=7.2 cm/day`（基质导水率，仅 Green-Ampt 地表入渗，华南暴雨 >15mm/h 自然触发超渗产流）
      + `ksat_drainage=[12.0, 1.9, 0.48, 0.05] cm/day`（仅 LayerCascade 层间排水上限）；
      后续引入 Kozeny-Carman 修正公式计算 Ksat
- [x] **大孔隙优先流**：`bypass_fraction=0.2`（config 开放）——超过基质 Ks 的地表积水
      20% 绕过表层直接注入 **L2**，携带**原始降水化学**（非 L1 平衡溶液、非纯水）
- [x] **硝化产酸限 L1**：`run_monthly_multi_layer` 仅 L1 执行 `advance_nitrification`
      （2H⁺ 产酸不再逐层重复，修正 4 层 pH 剖面行为）
- [x] **保留 `stored_water` 状态**（θ/ψ 状态迁移留待 v0.5.3）
- [x] 验收：质量守恒（入渗+径流=降水）、超渗产流自然出现、表层 pH 回落方向正确
      （实测：入渗 66%、径流 34%、优先流 20%、初始表层 pH 4.63）

#### v0.5.3 — VGM + Feddes ET + 级联重构（状态迁移）
- [ ] **van Genuchten-Mualem**：`LayerCascade` 状态从 `stored_water`（L/ha）迁移至
      **θ（体积含水量）+ ψ（基质势）**；θ_s≡porosity 数学自洽；层间达西通量（可上可下，
      对接 WRF 陆面水势）
- [ ] **VGM 参数三级优先级**：①`layer_overrides` 显式配置（`vgm_theta_r`/`vgm_alpha`/`vgm_n`）
      ②基于 `clay_pct` 连续回归（θ_r=0.01+0.002×clay；α=0.04−0.0006×clay；
      n=1.5−0.008×clay，Saxton & Rawls 2006 + 红壤修正，避免 Carsel & Parrish 离散查表突变）
      ③全局红壤兜底（0.08/0.015/1.25）；`l=0.5` 固定
- [ ] **初始 θ 田间持水量校准**：废弃"50% 饱和"硬编码（物理审查：50% 饱和度反解 ψ≈-280cm 近
      萎蔫点，过湿不符合农业土壤）；新增 `initial_psi_cm=-100`（config 默认），经
      `vgm_theta_from_psi` 正算 θ（L1≈0.81θ_s / L4≈0.88θ_s，下层更湿合理）
- [ ] **Feddes ET**：Oudin (2005) 公式为主 + 固定气候态兜底（`latitude`/`pet_method`/
      `pet_monthly_climate`/`pet_correction_factor` 配置）；`LayerCascade.run()` **最前端**
      执行 ET 扣除（AET_i = PET×f_root,i×α(θ_i)）；根系权重 L1 60%/L2 30%/L3 10%/L4 0；
      雨季滞水→旱季 ET 抽干，闭合水量 + 干湿交替驱动气体交换/硝化触发
- [ ] **LayerCascade 重构（下游接收能力）**：可排水量 = 当前总水量 − 有效持水空间；
      界面最大导水通量 = min(上层, 下层 `ksat_drainage`)（木桶短板原理）；实际排水
      = min(可排水量, 界面通量×Δt×面积)
- [ ] **OM 矿化产 CO₂ 模块**：温度驱动有机质分解 → 增加层内 CO₂/H₂CO₃，强化表层酸性
      （与 θ/ψ 联动：含水量影响分解速率）
- [ ] **输出扩展**：新增 `AET_mm`、`soil_moisture_L1~L4` 列（验证水分平衡闭合）
- [ ] **PET 敏感性扫描**（年 PET 600~1400 mm 扫描，固定其他参数）：验证 L1/L2 干湿交替
      与 pH 回落至 4.5~5.5

#### v0.6.0 — 化学子步长拆分（物理-化学范式转变）
- [ ] **逐场化学平衡**：`phreeqc_engine` 接口从 `run_monthly` 改为 `run_event`

- [ ] **PET 升级 Hargreaves-Samani**（补充 T_max/T_min 输入，区分干热/湿热）；

**工程要点**：
- 三阶段 = 改动量/风险从小到大（v0.5.2 仅替换入渗函数；v0.5.3 状态迁移；v0.6.0 循环重构）；
