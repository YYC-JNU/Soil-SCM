## 3. 水文计算流程（`src/hydrology.py`）

```
每月:
  1. 随机降雨: rng(seed + y*12+m); N~U(4,12); P_j = P × exp_w_j/Σexp_w (总量守恒)
  2. Horton 单场: A_j = fc×T + (f0−fc)/k·(1−e^(−kT)), T=2h, k=5/h
     入渗_j = min(P_j×0.75, A_j); 月入渗=Σ; 月径流=P−月入渗
  3. 级联 (每层):
     sat_i = φ_i×depth_i×1e5 (L/ha); space_i = 0.5×sat_i
     avail = 来水_i + stored_water_i
     drainable = max(0, avail − space_i)
     ksat_cap = Ksat_i×10000×30×10 (L/ha/月)
     drain_i = min(drainable, ksat_cap)
     retained = avail − drain_i; overflow = max(0, retained − sat_i)
     stored_water_i = min(retained, sat_i); runoff_extra += overflow
     来水_{i+1} = drain_i
```

## 4. 触发规则

| 情况 | 行为 |
|------|------|
| n_layers=4 且未配置 layer_overrides | **自动启用内置水文默认** |
| n_layers>1 且 layer_overrides 含水文字段 | 启用水文（用户配置优先） |
| n_layers>1 且 layer_overrides 不含水文 | 不启用（现状 precip_infiltration） |
| n_layers=1 | 完全原路径（回归护栏） |

## 5. 运行验证（2026-08-17，2 年 4 层 natural，seed=42）

`tools/plot_v0_5_hydrology_baseline.py`：

| 指标 | 旧基线 (precip_infiltration=0.05) | v0.5.0 水文模式 |
|------|----------------------------------|-----------------|
| 月入渗量 | 7.9 mm（年 95mm，5%） | **110 mm**（年 ~1349mm） |
| 表层 pH（末年末值） | 3.79（缓降） | **6.90**（大幅升高） |
| L1 AlX₃ | 36,364 | 24,315（表层淋失加强） |
| L4 AlX₃ | 36,033 | **61,193**（底层累积，排水带 Al 下移） |

**科学解读（基线漂移如实记录）**：
- **入渗量增 ~14 倍**：表层稳渗率 0.4mm/min（24mm/h）远超月平均降雨强度（~10mm/h）→ 近全入渗（0.75 上限主导）。这是"土壤入渗能力"参数与"月均强度"假设匹配的固有结果。
- **表层 pH 升高**：大量入渗稀释 + 碳酸（HCO₃⁻）缓冲增强，pH 从酸性基线升至 ~6.9。与真实红壤（pH 4~5）偏离——提示参数组合（0.75 系数/入渗率/历时假设）需结合研究区标定。
- **AlX₃ 垂直重分配**：表层淋失加强（L1 减），底层累积（L4 增 70%）——Ksat/持水垂直结构使 Al 下移而非耗尽。
- **Good/Bad 并存**：水文物理（Ksat 限制/持水缓冲）方向正确，但入渗量级显著改变既有基线——**必须结合研究区实测标定 0.75 系数与降雨假设**后才能作定量结论。

## 6. 局限与后续

- **月平均强度 vs 次降雨强度**：场次历时固定 2h 假设简化；超渗径流依赖强度分布，需实测标定。
- **单层不启用**：n_layers=1 保持 precip_infiltration 路径。
- **无蒸散发/作物需水**：出流未考虑 ET 消耗。
- **Ksat 月尺度通常不限制**：持水缓冲为主，Ksat 在暴雨持续期才显著。
- **标定方向**：表层入渗系数 0.75、稳渗率、降雨历时/场次假设为可调参数（config/layer_overrides），建议结合研究区红壤实测标定。
