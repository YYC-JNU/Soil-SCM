## 四、风险与纪律

1. **D3 是核心科学改动**：伴随淋失直接改变 Fertilizer 情景盐基平衡 → 需 grill-me 敲定扣除对象避免与 v0.6.1 Q3 双重计数
2. **D2 避免 KINETICS 回退**：v0.3.0 证伪（冻结矿物切断 L2 回补→加速耗尽）→ 集总风化注入是 safer 方向
3. **性能**：HX 使每步 PHREEQC 慢 3~5 倍，30 年全量需数小时 → `--scenario X` 分批断点续跑
4. **版本纪律**：v0.7.0 独立 spec+tag，发布前与用户确认编号
5. **科学诚实**：pH 方向带是方向性验收（同 v0.5.3/v0.6.0/v0.6.1 口径），不承诺具体值
