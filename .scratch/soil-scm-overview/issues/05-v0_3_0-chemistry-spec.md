# 05 — v0.3.0 化学机理收尾 spec（L4 硝化两步 + L5 HCO₃⁻ 电荷平衡）

**What to build:** Soil-SCM v0.3.0 两个化学机理工单的规格——L4 硝化两步（模型库存层）与 L5 溶液电荷平衡 HCO₃⁻ 缓冲。工单 06-10 由本 spec 拆分。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

---

## Problem Statement

1. **施肥氮形态时程无法模拟**：官方 `phreeqc.dat` 的 N 氧化还原平衡（`2NO₃⁻+12H⁺+10e⁻=N₂+6H₂O`）将任何注入溶液的无机氮（NH₄⁺/NO₃⁻）热力学平衡为惰性 N₂——实测 pe=0~12 下溶液 N(-3)/N(5) 均≈0。旧实现"一步尿素硝化加 NO₃⁻+2H⁺"的氮同样全部流失为 N₂（既有局限）。施肥产酸时程无法表达。
2. **初始溶液电荷平衡不真实**：电荷盈余依赖保守 Cl⁻ 补足（Q13）；原阳离子浓度估算（2e-3 mol/L）导致盈余高达 3.6e-3 mol/L，pH=5 时需 0.09 mol/L 无机碳才能以碳酸平衡，物理不可能且 PHREEQC 数值失稳。

## Solution

- **L4 模型库存层硝化**：尿素/NH₄⁺/NO₃⁻ 为纯模型状态（不注入 PHREEQC 溶液平衡），按月以简化一阶推进（k₁ 尿素水解=1.0、k₂ 硝化=0.4）；**硝化产酸 `2H⁺/mol N` 注入 REACTION**。
- **L5 电荷平衡物理化**：初始 HCO₃⁻ 由亨利定律 + pCO₂ 决定（与 GAS_PHASE 联动）；电荷盈余由碳酸体系按解离平衡占比吸收；Cl⁻ 保留微量；`_check_charge_balance` 用碳酸真实电荷。
- **阳离子浓度物理化**：初始总阳离子浓度 2e-3 → 5e-5 mol/L（红壤淋溶液实测量级），使盈余可在碳酸体系内自然平衡。

## User Stories

1. 作为土壤学家，我希望施肥氮以"尿素→NH₄⁺→NO₃⁻"两步形态演化，以便观察施肥产酸时程而非一步瞬时酸化。
2. 作为土壤学家，我希望施肥情景的 pH 酸化响应来自硝化产酸（2H⁺/N），以便化学效应与氮循环一致。
3. 作为模型开发者，我希望氮形态库存（尿素/NH₄⁺/NO₃⁻）可作为状态输出，以便诊断长期模拟中的氮分配。
4. 作为模型开发者，我希望氮形态推进逻辑独立成函数，以便将来升级为 PHREEQC KINETICS 时替换实现即可。
5. 作为土壤学家，我希望初始溶液 HCO₃⁻ 由土壤 pCO₂ 决定，以便溶液碳酸体系与气相 CO₂ 自洽。
6. 作为土壤学家，我希望初始溶液电荷平衡不再依赖大量保守 Cl⁻，以便溶液化学接近真实红壤淋溶液。
7. 作为模型开发者，我希望初始溶液阳离子浓度处于实测量级，以便电荷盈余可被天然阴离子承担。
8. 作为模型开发者，我希望简化引擎（降级兜底）保持既有经验行为，以便降级时流程稳定、边界清晰。
9. 作为土壤学家，我希望多层模型 pH 垂直梯度反映真实红壤剖面（表层酸化），以便剖面化学判断可信。
10. 作为模型开发者，我希望全部新参数集中在常量模块并可文档化。
11. 作为土壤学家，我希望 30 年模拟中施肥氮的 NH₄⁺ 峰值与逐月递减可观测，以便校准硝化速率。
12. 作为模型开发者，我希望 SELECTED_OUTPUT 保留总氮输出，以便多层层间平流氮传递不受影响。

## Implementation Decisions

- **架构（L4 库存层）**：氮形态（尿素/NH₄⁺/NO₃⁻）为 `SoilState` 模型状态字段；`advance_nitrification` 为独立模块级函数，按月推进水解与硝化，返回本月产酸量；**REACTION 仅注入 `H+ = 2×硝化量`**（NH₄⁺/NO₃⁻ 不注入——注入即被平衡为 N₂，实测证据）；月度步后氮库存由模型推进而非溶液输出覆盖。
- **接口契约**：`advance_nitrification(state, action, k1, k2)` 修改库存并返回 `{'H+': nitrified×2}`；引擎月度步在构建 PHREEQC 输入前调用。
- **L5**：HCO₃⁻ 由亨利定律 + 碳酸一级解离从 pCO₂ 计算；电荷盈余按解离平衡占比（H₂CO₃/HCO₃⁻/CO₃²⁻）分配吸收（补足后仍处碳酸平衡，`_check_charge_balance` 拆分可精确还原）；Cl⁻ 保留微量常量；`_check_charge_balance` 从 C(4) 按解离平衡拆分计算真实电荷（替代旧一价简化）。
- **物理化修正**：初始总阳离子浓度 5e-5 mol/L；使多层 pH 梯度方向翻转（表层酸/底层碱，符合真实红壤剖面）。
- **常量收敛（Q19）**：全部新参数（k₁/k₂、亨利常数、碳酸解离常数、水的离子积、Cl⁻ 残留、阳离子浓度）入常量模块。

## Testing Decisions

- **测试接缝**（沿用项目既有约定）：① `run_monthly_step`（月度化学步，最高接缝）——L4；② `InitialConditionBuilder.build_solution`——L5。
- **好测试**：只测外部行为（REACTION 内容、月度步后库存、HCO₃⁻/Cl⁻ 数值、电荷不平衡度），不测内部细节。
- **测试模块**：硝化行为（新增）、碳酸平衡（新增）、既有电荷平衡测试更新、既有多层/SURFACE 断言按物理化新基线更新。
- **先例**：既有 `test_nitrification.py` 风格与 `test_multilayer.py`、`test_surface.py` 一致（复用 profile/soil_info fixtures）。

## Further Notes

- **N→N₂ 为既有局限**：旧实现氮同样全流失为 N₂，库存层首次让氮形态可追踪。
- **科学行为变化（须记录）**：L5 阳离子物理化使多层 pH 梯度方向翻转；10 年 E2E pH 平缓至 6.46、AlX₃ 稳定 6.8e4，与既有 L2 修复文档记录一致。
- **降级边界**：simplified 引擎不参与氮形态推进（占位保留），施肥走经验产酸系数。
- **参数可修改性**：k₁=1.0、k₂=0.4 为默认值，可在常量模块调整并文档化。
